## What You'll Learn

What I wanted to do with this course is give you a set of practices that you can use in your workplace to actually start shipping code.

I'm going to show you a five-step system that goes from [grilling](https://www.aihero.dev/ai-coding-dictionary/grilling), to creating a [spec](https://www.aihero.dev/ai-coding-dictionary/spec), to creating [tickets](https://www.aihero.dev/ai-coding-dictionary/ticket) for that spec, to implementing, and then doing review.

![Five-step system: grilling, spec, tickets, implementation, review](https://res.cloudinary.com/total-typescript/image/upload/v1785858291/ai-hero-images/pswtqhfo8ayjla4j7jwl.png)

I felt comfortable creating a course at this point because these five steps have really remained unchanged, no matter what else I do, what else I'm playing around with.

Having these five steps feel absolutely essential to shipping great work.

## Context Management and Breaking Up Work

I'm going to take you through how we make decisions on context management, thinking deeply about how [attention degrades](https://www.aihero.dev/ai-coding-dictionary/attention-degradation) as you get further into the [context window](https://www.aihero.dev/ai-coding-dictionary/context-window).

When you should [compact](https://www.aihero.dev/ai-coding-dictionary/compaction), when you should [clear](https://www.aihero.dev/ai-coding-dictionary/clearing), when you should [hand off](https://www.aihero.dev/ai-coding-dictionary/handoff).

And we'll be going deep on breaking up huge chunks of work into things that [agents](https://www.aihero.dev/ai-coding-dictionary/agent) can handle.

## Which Agent Should You Use?

You're probably thinking, which agent should I use? Well, my answer to that is to use any agent that can run in a terminal and use [skills](https://www.aihero.dev/ai-coding-dictionary/skill).

So that is basically all of them. Claude Code, Codex, OpenCode, GitHub Copilot, whatever the Gemini one is.

![List of coding agents: Claude Code, Codex, OpenCode, GitHub Copilot](https://res.cloudinary.com/total-typescript/image/upload/v1785858292/ai-hero-images/agxrhainft5zak68lcyb.png)

This course is not about focusing on one particular agent, learning the quirks of that agent. It's about teaching you the fundamentals so that you can use any agent well.

And everything that we're going to be covering is going to be delivered through skills. So you can take those skills and use them in any agent.

## Prerequisites

The prerequisites for this course are really two things:

- Can you read code? Good.
- Can you use a terminal?

Reading code will allow you to navigate the code base a little bit easier, understand exactly what's going on. You don't necessarily even need to be able to write code.

Just an understanding for the vague shapes of things will be helpful.

And then you'll also need to be able to find the terminal to use some basic terminal commands like `cd` and `ls` and understand vaguely what's happening in there.

## What You'll Be Able to Do

Once you're done with the course, you'll be able to ship enormous amounts of work at super high quality.

This won't be done by making the [model](https://www.aihero.dev/ai-coding-dictionary/model) better, it will be done by making you better, by giving you the skills you need to drive agents better.

And that's what this course is for, to level you up to be able to take your software development with AI to the next level.
