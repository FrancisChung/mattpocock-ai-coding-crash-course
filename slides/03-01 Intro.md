# Intro

In this course, I'm going to be primarily using [Claude Code](https://code.claude.com/docs/en/setup) as my [agent](https://www.aihero.dev/ai-coding-dictionary/agent) for driving the lessons, demonstrating things, and showing you how agents in general work.

I'm doing this because it's a very popular [harness](https://www.aihero.dev/ai-coding-dictionary/harness), you may have used it yourself, and it's the one that I personally use the most right now.

**However, this course is harness agnostic.** You can choose whatever harness you like, as long as it runs in a CLI. Pick the tool that works best for you.

## An Optional Primer Section

For folks who've never used a coding harness before, or who just want to get more out of Claude Code, I've provided an optional primer section so that you can get the basics before we get started.

It will give you a nice grounding of all of the things that you'll need to know about your agent before getting started with the course.

And if you're already experienced with your harness of choice, you'll probably still pick up a few tips - because I'm not just covering the basics. There are a couple of advanced things in there too.

So nice work, and I will see you in the next one.
